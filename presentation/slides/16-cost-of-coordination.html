What goes wrong without a guard

Some issues

Borrowed evidence

A seat’s own repo-wide search returned a rival seat’s raw finding — copied verbatim, caught only after the fact.

No “still waiting” status

A hook accepted only finished/failed as a stop reason — so the referee’s ordinary pause-and-wait kept getting rejected and retried.

Builds aren’t locked

A seat ran a full build in an untracked directory no guard was watching — a race between seats could fail a build for reasons that have nothing to do with the code.

Prose, not JSON

A 240 KB prompt buried the output contract under an inlined diff. Gemini answered in prose, no fence, and its one real finding almost went with it.

None of this was a seat disobeying an instruction — each was a gap in what the harness watched for or allowed. Fixed with event-driven waiting, scratch outside the repo, a write-nothing rule, and referencing the diff by path instead of inlining it.
