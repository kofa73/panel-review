Lessons learnt

Pin behavior, not wording

A check required README to say the exact error string a CLI update had already removed — it would have failed the fix, not the bug.

One owner per fact

The same rule lived in three docs and drifted. Say it once; point everything else at it.

Re-verify after every upgrade

A changelog describes intent, not shipped behavior. Re-run a real probe — don’t just re-read release notes.

Don’t trust self-report

A seat can misdescribe its own actions. Independent logs caught copying a transcript summary would have missed.

Keep the prompt lean

An inlined diff buried the output contract and got prose instead of JSON. Reference bulk content; keep the contract salient.

All five came from incidents on the previous slides — generalized once each was understood.
